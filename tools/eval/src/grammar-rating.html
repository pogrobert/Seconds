Sites built from two layers of design rules

No hand-made templates this time. Each page combines one of 6 layouts with one of 6 type systems, and every combination is allowed. Jev read the owner's words and scored every layout and type system. Code then picked combinations in proportion to those scores, and a text model wrote the words once per salon. Each site took about 1.2 s (Jev and the words run at the same time) and under a tenth of a cent, measured on this computer.

For each site: would you proudly hand it to the owner? 1 no, 3 it's fine, 5 yes, without changing anything
